## Page 69

- Manual page: `7-23`
- Content: `7-71. Abbreviated Troubleshooting`, `Table 7-5. Abbreviated Troubleshooting`
- Verified workflow summary:
  - Step `1`: Apply power and observe display. Normal indication: display shows `uLAb UP`. If abnormal: go to step `2`.
  - Step `2`: Observe bus and status LEDs. Normal indication: some bus and status LEDs are on. If abnormal: check power supply.
  - Step `3`: Check for bus activity using logic probe. Normal indication: bus active. If abnormal: check `U3` pins `Reset 36 High`, `Hold 39 Low`, `Clock 37 Flashing`, `Ready 35 High`.
  - Step `4`: Start `SA Test Loop` by pressing `RESET` and sliding `SA` switch up and down once. Normal indication: output LEDs and display segments light, speaker beeps once, and `Vcc` signature agrees with `Table 7-1` or `Table 7-2`. If abnormal: proceed to step `6` for freerun test.
  - Step `5`: Take signatures per paragraph `7-52` or `7-54`. Normal indication: signatures correct per `Table 7-1` or `Table 7-2`. If abnormal: locate bad signature, trace signal path back until correct signature is found, isolate fault.
  - Step `6`: Start `Freerun Test`: slide `8` bus switches up and slide `FR` switch up. Normal indication: `A0` through `A13` address bus LEDs lit, `A14` and `A15` flashing, status LEDs show `READ on`, `WRITE off`, `ROM/RAM/INPUT/OUTPUT flashing`. If abnormal: check control lines, clock, and `U3` data-bus pins.
  - Step `7`: Take signatures per paragraph `7-68`. Normal indication: signatures correct per `Table 7-3`. If abnormal: locate bad signature, trace back, isolate fault.
  - Step `8`: Take signatures per paragraph `7-70`. Normal indication: signatures correct per `Table 7-4`. If abnormal: if one data-bus signature is bad, check corresponding ROM output pin; if all data-bus lines are bad, check ROM enable and address pins; if those are good, check bus device-enable pins.
- Full reference image: [page-69.png](/home/cartheur/ame/aiventure/aiventure-github/cartheur/hp5036a/docs-classified/service/05036-90001/figures/page-69.png)
